Liga do Povo

Local discovery Public fields Live
Visit the site Projects

Pickup-football directory for finding public fields and real games by place, time, intensity, and availability, with recurring listings, guest RSVPs, gear coordination, and field reports.

How it works

Open games and public fields are organised by time, distance, intensity, and available places.

The directory distinguishes Liga-managed attendance, external registration, and informational community listings instead of inventing capacity or reservation status.

Recurring series, guest RSVPs, waitlists, gear claims, directions, teams, and match results share one game record.

Trust model

A field is not described as reserved unless a host or source confirms it. Community field submissions remain visibly pending until reviewed.

Post-game reports record whether the game happened, whether the field was usable, and whether the published description matched what players found.

Current state

Live at ligadopovo.com. The current build uses shared Supabase data, retains a local fallback, and verifies recurring series, area preferences, and core participation paths with dedicated checks.
