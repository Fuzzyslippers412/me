A shared entry point

The portal combines a community entry page with a resource catalog. Guides and local information share a navigation context.

The work described here concerns content organization and movement between French and English, not publishing the information of people using the service.

Engineering frame

Constraint
Guides, resources and businesses need to remain recognizable when a reader changes language or follows an older link.
Decision
The entry page uses explicit language state and shared catalog data. Legacy addresses are routed to the corresponding destination.
Limit
This review covers page and resource code. It does not establish a public release and does not include member data.
