Project

MyCasaPro

Home operations LTI multi-agent In the lab
Visit MyCasaPro Projects

Local-first home operations system with a Next.js UI and FastAPI backend. LTI multi-agent teams (manager, finance, maintenance, security, contractors, projects) coordinate through scheduling and approvals, backed by a SecondBrain knowledge vault, user-owned connectors, and integrated Railgun private payment linkage. The core vendor flow is preflight-verified end to end (relationship -> contract -> milestone acceptance -> linked payment).

Use

  • Homeowners and small teams managing home operations locally.
  • Operators who need offline-first control and fast local setup.
  • Teams that require private payments and agent-driven workflows.

System

  • Next.js UI + FastAPI backend with dashboards, inbox, and approvals.
  • Multi-agent teams with scheduling, routing, and workflow coordination.
  • SecondBrain knowledge vault for durable memory and context.
  • Preflight verification that exercises relationship -> contract -> milestone acceptance -> linked payment.
  • User-owned connectors (Gmail, WhatsApp, Calendar) and integrated Railgun private payment linkage.

Current State

In-lab build with multi-agent coordination, SecondBrain memory, and a preflight-verified vendor payment flow with integrated Railgun private linkage.
