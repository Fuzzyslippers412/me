Notes sur le système

Une plateforme domestique locale avec une interface native pour la télévision. Un hub conserve les registres ; les appareils gardent un cache et mettent les modifications autorisées en attente.

L’appareil et le hub

L’interface Android TV utilise Kotlin et Compose for TV. Le hub local conserve l’état de référence dans SQLite ; le client garde des projections en cache et une file persistante d’actions.

Le canal appairé utilise des identifiants à portée limitée et un transport avec vérification du certificat. Cette présentation exclut la configuration domestique et les informations d’accès.

Des conflits explicites

Une modification indique la révision du registre sur laquelle elle repose. Si un autre appareil a changé ce registre, le hub renvoie un conflit au lieu d’écraser l’état plus récent.

Un résultat incertain ne justifie pas un nouvel identifiant d’opération : la tentative suivante doit rester reconnaissable comme la même commande.

Reçus et inventaire

Le module cuisine conserve le reçu séparément de l’inventaire courant. Les lignes sont relues et confirmées avant l’importation ; un reçu accepté ne peut pas être importé à nouveau.

Le code examiné accepte des images ou du texte, mais ne démontre pas de reconnaissance automatique des caractères. Les corrections de l’inventaire ne réécrivent pas le document original.

Cadre technique

Contrainte
La télévision doit rester utilisable après une coupure sans devenir une seconde source de vérité. Son cache représente les registres, sans les remplacer.
Décision
L’appareil enregistre une opération avant l’envoi et conserve son identifiant lors des nouvelles tentatives. Le hub distingue les actions appliquées, déjà appliquées, conflictuelles et refusées.
Vérification
J’ai examiné le code et les résultats enregistrés de tests et de compilation du 27 octobre 2026. Ils ne démontrent ni une validation sur une télévision physique ni un lancement public.

État actuel

Développement privé. Cette présentation décrit le code du 27 octobre 2026, pas un service public.
