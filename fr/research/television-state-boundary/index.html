Ce qu’un client TV doit conserver

10 novembre 2026

Note de Armel Tenkiang.

Sur cette page
  1. Deux responsabilités
  2. Hors ligne ne signifie pas tout autoriser
  3. La limite de vérification
  4. Portée de cette note

Un cache rend un appareil déconnecté utile. Il ne lui donne pas autorité sur toutes les données du système.

Deux responsabilités

Dans Home, le hub local conserve les registres de référence. Le client TV présente une projection en cache et garde les actions en attente de confirmation. Cette séparation évite de confondre l’état affiché avec l’état accepté par le système.

Hors ligne ne signifie pas tout autoriser

Un client peut continuer à montrer ce qu’il connaît sans prétendre que toute opération est disponible. Les actions autorisées entrent dans une file ; le résultat vient du hub. La révision attendue explicite l’état sur lequel repose la modification.

Si le registre a changé, le conflit doit revenir au lecteur. La continuité de l’interface ne justifie pas un écrasement silencieux.

La limite de vérification

L’implémentation examinée comprend une interface Android TV native, une file persistante et un canal appairé. Les résultats enregistrés concernent ce code : ils ne remplacent pas une validation sur une télévision physique, avec un réseau et des entrées réels.

Portée de cette note

Cette note décrit le code de Home du 27 octobre 2026 et les résultats de tests et de compilation déjà enregistrés. Elle ne revendique ni validation sur une télévision physique ni lancement public.
