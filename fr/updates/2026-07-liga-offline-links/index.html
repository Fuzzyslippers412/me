Des liens stables vers les matchs récurrents pendant les pannes

18 juillet 2026 Traduit 12 octobre 2026 Liga do Povo Modification vérifiée 645f372

Note technique d’Armel Tenkiang.

Les identifiants des matchs récurrents sont devenus déterministes afin qu’un match connu conserve le même lien lorsque le backend partagé est indisponible.

Ce qui a changé

La matérialisation hors ligne dérive désormais le même identifiant d’occurrence que les parcours utilisant des données préchargées ou partagées.

Cette petite invariance empêche les adresses de matchs enregistrées ou partagées de changer simplement parce que l’application s’est rabattue sur des données locales.

La modification sert un objectif plus large : la recherche doit se dégrader sans rompre l’adresse d’un match communautaire existant.

Note d’ingénierie

Les identifiants stables délimitent la reprise. Un match récurrent doit conserver la même adresse, que son enregistrement provienne du stockage partagé ou d’un mécanisme local de secours.

Provenance

Cette note s’appuie sur le code vérifié du projet au commit 645f372. Elle documente une modification logicielle, pas une actualité personnelle.
