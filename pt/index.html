Uma plataforma doméstica local com interface nativa para televisão. Um hub mantém os registos; os dispositivos guardam uma cache e uma fila de alterações permitidas.

O que acontece quando uma ação é repetida?

O dispositivo guarda a operação antes do envio e mantém o mesmo identificador nas tentativas seguintes. O hub distingue ações aplicadas, já aplicadas, em conflito e rejeitadas.
