MyCasaPro

Operações domésticas LTI multiagente Em laboratório

Projeto de Armel Tenkiang.

Visitar MyCasaPro Projetos

Sistema local-first de operações domésticas com UI em Next.js e backend FastAPI. Equipes LTI multiagente (gestor, finanças, manutenção, segurança, fornecedores, projetos) coordenadas via agendamento e aprovações, memória SecondBrain, conectores do usuário e ligação de pagamento privado integrada com Railgun. O fluxo de fornecedores é verificado ponta a ponta no preflight (relacionamento -> contrato -> aceitação de marco -> pagamento vinculado).

Uso

  • Proprietários e pequenas equipes gerindo operações domésticas localmente.
  • Operadores que querem controle offline-first e configuração rápida.
  • Equipes que exigem pagamentos privados e fluxos guiados por agentes.

Sistema

  • UI Next.js + backend FastAPI com dashboards, inbox e aprovações.
  • Equipes multiagente com agendamento, roteamento e coordenação de workflows.
  • SecondBrain como cofre de conhecimento para memória durável.
  • Verificação preflight do fluxo relacionamento -> contrato -> aceitação de marco -> pagamento vinculado.
  • Conectores do usuário (Gmail, WhatsApp, Calendar) e ligação de pagamento privado Railgun integrada.

Notas de programação

  • 23 de fev. de 2026Signed events and private settlement linkage

Estado atual

Build em laboratório com coordenação multiagente, memória SecondBrain e fluxo de pagamento de fornecedores verificado em preflight com ligação privada Railgun integrada.
