Article intake separates event reports from context

April 23, 2026 Respometer Verified change 4c3aed4

Programming note by Armel Tenkiang.

Respometer strengthened article-shape detection so live blogs, opinion pieces, explainers, and thin briefs are not treated as discrete event reports.

What changed

Source URLs and extracted text now help distinguish rolling coverage, opinion, analysis, features, and explainers before an event assessment is produced.

Article character and sentence counts establish an evidence floor for very short reports instead of treating any successfully parsed page as sufficient.

Tests cover URL-based classification and thin article bodies so the intake path can request more evidence or use a source as context rather than overstate what it supports.

Engineering note

The presence of a URL is not evidence quality. Source shape has to be classified before a system can decide whether the material supports an assessment, supplies context, or requires corroboration.

Provenance

This note is based on verified project source at commit 4c3aed4. It records a programming change, not a personal-status update.
