Article intake separates event reports from context

April 23, 2026 Updated September 1, 2026 Respometer Verified change 4c3aed4

Technical note by Armel Tenkiang.

Respometer strengthened article-shape detection so live blogs, opinion pieces, explainers, and thin briefs are not treated as discrete event reports.

What changed

Source URLs and extracted text now help distinguish rolling coverage, opinion, analysis, features, and explainers before an event assessment is produced.

Article character and sentence counts establish an evidence floor for very short reports instead of treating any successfully parsed page as sufficient.

Tests cover URL-based classification and thin article bodies so the intake path can request more evidence or use a source as context rather than overstate what it supports.

Classification before assessment

The intake path first asks what kind of source it has received. A discrete event report, a live blog, an opinion column, an explainer, and a background feature do not provide the same evidence shape even when each page can be parsed successfully.

URL patterns and extracted text are used together. The classifier can keep a source as context, request corroboration, or stop an assessment before a thin or rolling page is mistaken for a complete account of an event.

An evidence floor

Character and sentence counts provide a simple deterministic floor before model-assisted extraction is considered. These checks do not decide whether an article is true; they prevent extremely small bodies from being granted the same evidentiary weight as a developed report.

The assisted intake remains a proposal path. Structured validation, source records, scoring inputs, and revision history stay outside the model so an unavailable provider cannot erase the distinction between evidence and generated interpretation.

Revision without erased history

Public event pages can change as stronger sources arrive, confidence changes, or an actor assessment is corrected. The data model preserves score audits and revision records so the current result does not pretend to have been the only result.

Tests cover article-shape classification and thin-body handling alongside the scoring library and critical routes. The objective is not automatic certainty; it is a reviewable path from source material to a published assessment.

Engineering note

The presence of a URL is not evidence quality. Source shape has to be classified before a system can decide whether the material supports an assessment, supplies context, or requires corroboration.
